Componentes y responsabilidades

Archivo Acción Qué hace
PdfThumbnailSidebar.tsx Crear Panel lateral con miniaturas lazy. Recibe numPages, currentPage, onPageSelect, pdfData. Cada miniatura es un <Page> de react-pdf a escala pequeña.
PdfSearchBar.tsx Crear Input + contador "N / total" + botones ↑ ↓. Llama a la API de pdfjs para buscar texto y navegar entre coincidencias.
PdfViewer.tsx Modificar Añade showSidebar state (toggle ⊞), integra PdfThumbnailSidebar y PdfSearchBar en la toolbar existente. Layout flex row con sidebar condicional.

Decisiones técnicas clave

  • Miniaturas: <Page scale={0.12}> de react-pdf — mismo worker que ya usa el visor, sin librerías extra. Lazy via IntersectionObserver.
  • Búsqueda: API nativa de pdfjs (PDFDocumentProxy.getPage().getTextContent()) — extrae texto por página y hace matching. El resaltado lo gestiona el renderTextLayer que ya está activo.
  • Sin nuevas dependencias — todo con react-pdf + pdfjs-dist que ya están instalados.
  • Toggle sidebar: estado local en PdfViewer, persiste solo mientras la página está abierta (sin localStorage — YAGNI).
