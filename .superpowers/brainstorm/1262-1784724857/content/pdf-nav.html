¿Dónde viven los PDFs en MITIKUS?

Tres opciones de integración en la navegación

A

PDFs como ítem propio en el sidebar

Al mismo nivel que Docs y Hojas de cálculo. Ruta /pdfs. Listado + visor. Estructura idéntica a Docs y Sheets.

📄 Docs
📊 Hojas de cálculo
📑 PDFs
🔧 Herramientas
B

PDFs integrados dentro de Docs

La página /docs acepta tanto .docx como .pdf. Un solo listado unificado. Los PDFs muestran visor en lugar de editor Tiptap.

📄 Docs (docx + pdf juntos)
📊 Hojas de cálculo
🔧 Herramientas
C

PDFs dentro de Docs pero con pestaña separada

En /docs hay dos tabs: "Documentos" y "PDFs". Mismo sidebar, contexto unificado, pero listados diferenciados.

📄 Docs
Documentos PDFs
📊 Hojas de cálculo
