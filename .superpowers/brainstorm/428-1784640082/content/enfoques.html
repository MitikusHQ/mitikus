¿Cómo almacenamos y mostramos los documentos?

3 enfoques — mismo resultado visible, diferente complejidad técnica

A

Texto extraído en base de datos

Al subir el .docx, extraemos el texto y lo guardamos en PostgreSQL. El visor muestra el texto limpio. Arkos lo usa directamente.

Pros

  • Sin almacenamiento externo
  • Arkos integrado fácil
  • Rápido de implementar

Contras

  • Pierde formato (tablas, negritas)
  • No se puede descargar el original
B

Markdown en base de datos Recomendado

Al subir, convertimos el .docx a Markdown (pandoc). Guardamos el markdown en PostgreSQL. El visor renderiza el markdown con formato. Arkos lo lee igual.

Pros

  • Mantiene títulos, tablas, negritas
  • Ideal para Arkos (texto estructurado)
  • Sin almacenamiento externo

Contras

  • No conserva el .docx original
  • Requiere pandoc en el servidor
C

Archivo original en Vercel Blob

Guardamos el .docx tal cual en Vercel Blob Storage. El visor ofrece descarga directa. También extraemos texto para Arkos.

Pros

  • Archivo original siempre disponible
  • Puede abrirse en Word desde la app

Contras

  • Coste adicional (Blob Storage)
  • Más complejo
  • No hay visor inline en el navegador
